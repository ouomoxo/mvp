# mvp

대곡리 지형 분석 데모입니다. 공개 표고·위성 자료만으로 가시권, 예상 침투로, 화력 우선순위를 계산해 3D 지형 위에 보여줍니다. 가상 시나리오이며 실제 부대·시설·작전 정보는 들어 있지 않습니다.

- 사이트: https://ouomoxo.github.io/mvp/
- 단일 파일판: `offline.html` (내려받아 더블클릭, 인터넷 불필요)
